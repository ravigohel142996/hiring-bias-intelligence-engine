# Hiring Bias & Rule Collapse Intelligence Engine

A decision intelligence platform that stress-tests hiring rules under scale, bias, and adversarial scenarios.

This system simulates thousands of candidate profiles, applies human-defined hiring rules,
and uses ML to expose:
- Hidden bias amplification
- Rule dominance & collapse
- Unstable decision boundaries

⚠️ Not an ATS. Not automation.
This is a decision audit system.
